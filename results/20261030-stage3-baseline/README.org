folding of the ui into the core (Stage 4) can be checked against it.

  microseconds a frame. The bytes are comparable after a change; the microseconds are a
  machine's mood.

  counter, the timer, the CRUD and the editor, 3 starts and 5 s idle) of the same time are next
  to this directory, named =20261030T0255*= and =20261030T0256*=: 0 bytes a frame after the first
  for the counter, the cells and the dashboard, 802, 1102 and 2922 for the timer, the editor and
  the rows; idle: 0 frames, 0.0% cpu, 0 wakeups a second; startup about 190 to 200 ms.
