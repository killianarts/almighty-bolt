#+TITLE: Change-cost results

The five edits of =notes/change-cost.org= (decision record 0024), as patches against the commit they
started from (=c435ab6=, the base of the branches =change-cost/e1= to =e5=, where each edit is
a series of commits that the report reads). =e<n>/<part>.patch= is the diff of one part of edit
n, ignoring changes of white space: =tests= (the acceptance and model tests, shared), =model=
(the shared model of the task), and the app of each variant. =change-cost.sexp= is the table that
=scripts/change-cost-report.lisp= prints: for each edit and part, the lines of code added and
removed (no blank lines, comment lines or white-space changes), the files and the hunks.
=app-sizes.txt= is =scripts/app-size.lisp=: the lines of code of each app in each variant and the
number of distinct framework symbols it imports from the variant's packages.

The edits are not merged into the apps. To read or try one:
=git checkout change-cost/e3= (the branches are in the working copy that made them and are not pushed), or =git apply= a patch on
=c435ab6=.
